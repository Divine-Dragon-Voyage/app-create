App Create 用户使用文档（TXT版）

1. 适用场景
你是最终使用者，只需要会双击运行.

2. 你会拿到什么
- 安装包：AppCreateLauncherSetup-*.exe
- 安装后桌面快捷方式：App Create

3. 首次安装
1) 双击 AppCreateLauncherSetup-*.exe，按提示完成安装。
2) 安装完成后，桌面会出现 App Create 快捷方式。
3) 双击 App Create 启动。

4. 每次运行流程
1) 双击桌面 App Create。
2) 启动器会先检查是否有新版本。
3) 如果发现新版本，会弹出选择框：
   - 是：立即更新并启动
   - 否：跳过本次更新，直接启动当前版本
   - 取消：退出，不启动
4) 进入“应用创建启动器”窗口后，填写：
   - 开发者 ID 或链接
   - 数据文件路径（.xlsx/.xls/.csv）
5) 点击“开始运行”。

5. 数据文件基本要求
数据文件支持 .xlsx/.xls/.csv，且至少要有两列（列名支持中英文）：
- 应用名：应用名称 / 应用名 / App Name / Application Name
- 包名：应用包名 / 包名 / App Package Name / Package Name / Application ID

选择 .csv 时，脚本会在同目录自动生成工作文件：原文件名.__work.xlsx。
断点续跑所需的 status/progress_step 都写入这个工作文件，原始 .csv 不会被修改。

6. 注意事项
1) 日常请只点桌面 App Create 快捷方式
2) 运行期间不要频繁关闭自动化浏览器窗口。
3) 同一批次跑完前，不要改动 Excel 列结构。

7. 常见问题
1) 提示数据文件不存在：重新选择正确的 .xlsx/.xls/.csv 文件。
2) 提示开发者链接不合法：确认是 play.google.com 且包含 /developers/<id>。
3) 页面布局偶尔异常（左侧栏缺失/空白）：通常是页面加载问题，重试一次即可。
