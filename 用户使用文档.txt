App Create 用户使用文档（TXT版）

1. 适用场景
你是最终使用者，只需要会双击运行，不需要手动安装 Node/npm。

2. 你会拿到什么
- 安装包：AppCreateLauncherSetup-*.exe
- 安装后桌面快捷方式：App Create

3. 首次安装
1) 双击 AppCreateLauncherSetup-*.exe，按提示完成安装。
2) 安装完成后，桌面会出现 App Create。
3) 双击 App Create 启动。

4. 每次运行流程
1) 双击桌面 App Create。
2) 启动器会先检查是否有新版本。
3) 如果发现新版本，会弹出选择框：
   - 是：立即更新并启动
   - 否：跳过本次更新，直接启动当前版本
   - 取消：退出，不启动
4) 进入“应用创建启动器”窗口后，填写：
   - 开发者 ID 或链接
   - Excel 文件路径
5) 点击“开始运行”。

5. Excel 基本要求
至少要有两列（列名支持中英文）：
- 应用名：应用名称 / 应用名 / App Name / Application Name
- 包名：应用包名 / 包名 / App Package Name / Package Name / Application ID

脚本会自动维护两列（如果没有会自动新增）：
- status
- progress_step

6. 注意事项
1) 日常请只点桌面 App Create，不要直接点 run_windows.cmd。
2) 运行期间不要频繁关闭自动化浏览器窗口。
3) 同一批次跑完前，不要改动 Excel 列结构。

7. 常见问题
1) 提示 Excel 不存在：重新选择正确的 .xlsx/.xls 文件。
2) 提示开发者链接不合法：确认是 play.google.com 且包含 /developers/<id>。
3) 页面布局偶尔异常（左侧栏缺失/空白）：通常是页面加载问题，重试一次即可。
